# 다음 버전 스펙

다음 버전에 넣기로 한 기능을 적는다. 현재 버전은 0.2.1 이다.

- 작성일: 2026-11-12
- 상태: 계획(구현 전)

## 1. 프로젝트에 저장된 Auto scale 값 읽기

### 지금 동작

퀵 스파인은 `.spine` 프로젝트를 열면 그 안에 저장된 «마지막 내보내기 설정»을 읽어 팩 설정을 채운다. 이때 Auto scale(자동 배율)만 빠진다. 프로젝트에서 Auto scale 을 켜고 내보냈어도 퀵 스파인의 «자동 배율»은 꺼진 채로 열린다.

다른 경로로는 이미 읽는다.

| 설정을 읽는 곳 | Auto scale |
|---|---|
| `pack.json` (팩 설정의 Load, 이미지 폴더 안 파일) | 읽음 |
| 내보내기 설정 JSON (`packAtlas.autoScale`) | 읽음 |
| `.spine` 프로젝트의 마지막 내보내기 설정 | 읽지 못함 |

### 바꿀 동작

프로젝트에 저장된 Auto scale 값을 읽어 팩 설정의 «자동 배율»에 반영한다. 프로젝트를 열고 그대로 내보내면 Spine 에서 내보낸 것과 같은 배율로 묶여야 한다.

### 할 일

1. **필드 찾기.** 프로젝트 파일의 `PackSettings` 에서 Auto scale 이 몇 번 태그인지 확인한다. 이름이 붙지 않은 태그는 43번과 44번 둘이다(둘 다 정수형, 4.3.26 스키마에는 45번도 있다). 지금 가진 표본(Cat, TileObject)은 둘 다 0 이라 어느 쪽인지 가릴 수 없다.
2. **표본 만들기.** Spine 편집기에서 Auto scale 만 켜고 내보낸 뒤 저장한 프로젝트를 하나 만든다. 켜기 전 사본과 견줘 바뀌는 태그를 찾는다. 명령줄 내보내기(`-e`)는 프로젝트 파일을 바꾸지 않으므로 편집기에서 저장해야 한다.
3. **읽기.** `crates/spine-project/src/export_settings.rs` 의 `pack()` 에 그 태그를 `autoScale` 키로 넣는다. 나머지 경로는 이미 `autoScale` 을 읽으므로 더 고칠 곳은 없다.
4. **버전별 확인.** 3.8, 4.0, 4.1, 4.2, 4.3 스키마에서 태그 번호가 같은지 본다. Auto scale 이 없는 버전의 프로젝트는 꺼진 것으로 읽는다.

### 다 됐다고 보는 기준

- Auto scale 을 켜고 저장한 프로젝트를 열면 «자동 배율»이 켜져 있다.
- 끄고 저장한 프로젝트는 꺼져 있다.
- 그 프로젝트를 퀵 스파인으로 내보낸 atlas 가 Spine 이 내보낸 것과 같다(`scale:` 줄 포함).
- `dump_export_settings` 예제가 `autoScale` 을 찍는다.
- 태그를 읽는 테스트가 있다.

### 하지 않는 것

- 프로젝트 파일에 값을 쓰지 않는다. 퀵 스파인은 프로젝트를 읽기만 한다.
- 43번, 44번 가운데 Auto scale 이 아닌 쪽의 뜻은 이 항목에서 다루지 않는다.
